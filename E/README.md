# E · 统一评价与交付

E 负责把各模型预测同一站、同一小时的结果放在一起比较。模型代号见下表。模型输入从 A、B 的缓存读取，不需要手工合并大表。

| 代号 | 使用的信息 |
|---|---|
| B1 / B2 | 最近 48 小时最后一个有效浓度 / 昨天同小时浓度 |
| M1 / M2 | 历史六项污染物与缺失标记，分别使用时间网络和有地理图的网络 |
| A1 | M2 加历史温度、湿度、风速 |
| A2 | A1 加目标小时已发布的最高温、最低温、风力、预报年龄及缺失标记 |
| A3 | A2 的网络只保留站点自身的连接 |

## 怎样重跑

在仓库根目录先按首页说明生成 A、B 缓存，再执行：

```powershell
python -m E.experiment train
python -m E.experiment test
python -m E.evaluate
```

模型统一以最近有效 PM2.5 为起点并预测修正量。数值按训练期资料标准化，输入裁剪到正负八个标准差。缺值用训练均值和“未观测”标记表示。PM2.5 缺失标签不计损失。训练配置在 settings.json。训练覆盖所有选定站点，每轮在训练时间轴上按 12 小时间隔取起报时刻，起点随轮次变化；验证每 23 小时一次，以覆盖各小时；测试逐小时起报。每轮在验证集计算 MAE，保留四轮里表现最好的一次。以种子 17 比较两组配置，随后补跑 29 和 43；A1、A2、A3 继承 M2 的学习率和图配置。已通过验证的权重放在 C/runs 和 D/runs。train 会复用已有的日志和权重，全新训练可先将这两个目录重命名备份。

## 如何读结果

results/metrics.csv 记录每个种子的指标，summary.csv 记录三种子的均值和样本标准差。固定基线的标准差一栏留空。horizon=0 表示合并全部 24 步。MAE 是所有有效绝对误差的平均，RMSE 是平方误差平均后开方；最后再对种子求均值。主表仅比较所有方法都有预测且有真值的位置。coverage.json 记录这一步筛选前后的样本数。

原始预测以 float32 矩阵保存在 cache/predictions，三个轴依次是起报时刻、站点、预测步。origins.npy 是自 2015 年 1 月 1 日起的整点小时数；站序取自 cache/A/stations.csv；预测步对应 1～24。抽取标准长表样例可运行 `python -m E.sample`。case 图使用种子 17，以 24 步均完整的窗口中相对持久性改善最大、退步最大的两个样例展示边界情形；它们不能代表平均水平。

`python -m E.scenarios` 用训练集 90 分位数划分高污染目标，分别统计有无可用预报、历史记录稀疏与完整时的误差。生成的 scenarios.csv 和 ablation.png 随仓库提供。
