# C：简单基线与纯时间模型

本文件夹负责回答一个直接的问题：只看每个站自身的历史记录，未来 24 小时能预测到什么程度？

## 里面有什么

- `models.py` 中有两个简单基线和一个轻量 TCN。
- 持久性基线把过去 48 小时内最近一次有效 PM2.5 延续到未来 24 小时。
- 日周期基线用昨天相同小时的值预测今天。
- TCN 对每个站使用同一组参数，但不同站的数据不会在网络内部混合。这样它可以作为 D 中空间模型的公平对照。五层膨胀率为 1、2、4、8、16 的三点因果卷积覆盖 63 小时，能够完整利用 48 小时输入窗口。

## 输入和输出

TCN 输入 `x` 的形状是 `[批次, 48, 站点数, 特征数]`，输出是 `[批次, 站点数, 24]`。如果实验加入未来天气，创建模型时填写 `future_channels`，调用时再传入 `[批次, 站点数, 24, 天气特征数]`。

缺失值在进入模型前应由统一数据管线填补并保留缺失标记。模型也会把残留的 NaN 临时置零，防止训练崩溃。

## 方法来源

TCN 的设计参考 Bai、Kolter、Koltun 的序列建模比较研究。这里保留了因果膨胀卷积和残差结构，并为本项目增加了 24 步直接输出头。论文：<https://arxiv.org/abs/1803.01271>，作者代码：<https://github.com/locuslab/TCN>。
