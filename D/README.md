# D：站点空间图与时空模型

本文件夹负责检验“邻近站点的信息是否真的有用”。

## 里面有什么

- `make_graph` 根据经纬度给每个站连接验证集选定的 6 个近邻站，再补上自环并做行归一化。
- `STGCN` 先用覆盖 63 小时的门控时间卷积独立提取每个站的 48 小时历史，再沿站点图传播一次信息，最后一次输出未来 24 小时。
- 把 `self_only=True` 传给 `make_graph` 会得到只有自环的图，可用于空间消融。此时站点之间不会交换信息。

## 输入和输出

模型输入和 C 中 TCN 相同。站点顺序必须与构建邻接矩阵时 DataFrame 的行顺序完全一致。模型输出为 `[批次, 站点数, 24]`。缺少经纬度的站点应在构图前排除，并在结果中说明实际纳入数量。

在 `our` 目录运行 `python -m D.visualize_graph` 可以生成 `station_graph.png` 和 `graph_audit.csv`。该图直接读取 A 的 212 站名单和 E 的验证集选参记录，显示正式实验使用的图。

## 方法来源和项目适配

模型参考 Yu、Yin、Zhu 提出的 STGCN。原模型面向交通流预测，本项目使用相同的“时间卷积加图传播”思想，同时采用更小的隐藏层和直接 24 步输出头，以控制课程实验的训练成本。论文：<https://arxiv.org/abs/1709.04875>，作者代码：<https://github.com/VeritasYin/STGCN_IJCAI-18>。
